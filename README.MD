# Телеграм Бот

Этот репозиторий содержит телеграм-бота на Python. Он принимает фотографию лица,
отправляет её в OpenAI и возвращает пользователю анализ кожи с рекомендациями.

## Требования

- Python 3.8+
- библиотеки `python-telegram-bot` и `openai`

## Установка

```bash
pip install -r requirements.txt
```

Перед запуском необходимо задать переменные окружения `TELEGRAM_TOKEN` и
`OPENAI_API_KEY`.

## Запуск

```bash
python bot.py
```

Бот работает в режиме polling и выводит информацию в консоль.
